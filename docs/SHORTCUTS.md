# Pinterest Heist — Shortcuts

Turn Pinterest Heist on first: click its toolbar icon, or press **Alt + Shift + H**. The shortcuts below only work while it is on.

## Select

| Action | Shortcut |
|---|---|
| Select or deselect a pin | Hover the pin, then click the ◯ circle at its bottom left |
| Select a whole section (on a board page) | Hover the section card, then click its ◯ circle |
| Select a range | `Shift` + click a circle |
| Select a range (alternative) | `Ctrl` + `Shift` + click a pin |
| Box-select a group | `Ctrl` + drag across pins |
| Select everything in this board, section or profile | `Ctrl` + `A` |
| Deselect all | `Esc`, or **Deselect all** on the dock |

## Modes

| Action | Shortcut |
|---|---|
| Selection mode on/off (a plain click selects, all circles visible) | `S` |
| Leave selection mode | `S`, or `Esc` twice |
| Turn Pinterest Heist on/off for this tab | `Alt` + `Shift` + `H`, or the toolbar icon |

## General

| Action | Shortcut |
|---|---|
| Show the shortcut sheet | `?` |
| Open a pin in a new tab | Middle-click (Pinterest's normal behaviour, unchanged) |
| Send one pin to PureRef | Drag the pin onto the PureRef canvas |

- None of these keys do anything while you type in a search box or comment field.
- `Ctrl` + `A` on search results asks how many results to select, because search results almost never end.
- `Ctrl` + `A` on the home feed, a pin page or other endless pages selects only the pins loaded so far.
- You can change `Alt` + `Shift` + `H` at `chrome://extensions/shortcuts` (Edge: `edge://extensions/shortcuts`).
